# سند وضعیت سامانه «والیبال من»

**نسخه سند:** 1.3  
**نسخه محصول:** 0.9.3 MVP  
**تاریخ تهیه:** ۲۹ مهر ۱۴۰۵ / 21 October 2026  
**وضعیت:** آماده ارائه و اجرای آزمایشی در باشگاه

## ۱. معرفی محصول

«والیبال من» یک سامانه فارسی و واکنش‌گرا برای مدیریت عملیات روزانه باشگاه‌های والیبال است. این نسخه با تمرکز بر نیازهای هیئت والیبال استان طراحی شده و مدیریت ورزشکار، تیم، مربی، تمرین، حضور و غیاب، شهریه، رکوردهای تخصصی والیبال، گزارش و ارتباط با اعضا را در یک محیط واحد انجام می‌دهد.

این محصول در نسخه فعلی برای راه‌اندازی پایلوت در یک باشگاه و چند مربی آماده است. معماری داده به شکلی طراحی شده که توسعه آن برای چند باشگاه یا سطح استانی در نسخه‌های بعدی ممکن باشد.

## ۲. نقش‌های سامانه

| نقش | محدوده دسترسی |
|---|---|
| مدیر باشگاه | دسترسی کامل به کاربران، تیم‌ها، ورزشکاران، مالی، گزارش‌ها و تنظیمات |
| مربی | مشاهده ورزشکاران تیم‌های تخصیص‌یافته، حضور و غیاب، ارزیابی و یادآوری تمرین |
| مسئول مالی | صورتحساب‌ها، پرداخت‌ها، رسیدها، گزارش مالی و یادآوری شهریه |
| ورزشکار | مشاهده شهریه‌ها، پرداخت آنلاین آزمایشی، پرونده و رکوردهای شخصی |
| والد یا سرپرست | مشاهده اطلاعات، شهریه و رکوردهای فرزند متصل به حساب |

کنترل دسترسی در سمت سرور انجام می‌شود. مخفی‌کردن گزینه‌های رابط کاربری تنها لایه نمایشی است و جایگزین مجوزهای سرور نیست.

## ۵. معماری فنی

- **Backend:** Laravel 13 و PHP 8.4
- **Frontend:** Vue 3، TypeScript و Inertia
- **UI:** Tailwind CSS 4 و Lucide Icons
- **دیتابیس دمو:** SQLite
- **دیتابیس پیشنهادی Production:** PostgreSQL 17
- **Cache و Queue پیشنهادی:** Redis 7
- **ساختار:** Modular Monolith
- **احراز هویت:** Laravel Session Authentication
- **کنترل دسترسی:** Role Middleware و Query Scope
- **خروجی گزارش:** CSV و Print Stylesheet

## ۷. وضعیت نسخه 0.9.3

نسخه حاضر یک MVP کامل برای ارائه، دریافت بازخورد و اجرای پایلوت است. گردش‌های اصلی کسب‌وکار از ثبت ورزشکار تا حضور، شهریه، پرداخت، ارزیابی و گزارش به یکدیگر متصل‌اند.

### موارد لازم پیش از Production

1. انتخاب درگاه بانکی و افزودن Adapter آن با مرچنت‌کد واقعی
2. انتخاب سرویس پیامک و افزودن Adapter آن با API Key واقعی
3. انتقال دیتابیس به PostgreSQL
4. تنظیم Queue و Cache با Redis
5. دامنه، SSL و تنظیمات سرور
6. پشتیبان‌گیری زمان‌بندی‌شده
7. سیاست نگهداری اطلاعات پزشکی و رضایت‌نامه‌ها
8. تغییر حساب‌ها و رمزهای نمونه
9. پایش خطا، لاگ و وضعیت سرویس
