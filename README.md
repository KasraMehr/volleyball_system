# والیبال من

سامانه مدیریت باشگاه و ورزشکاران هیئت والیبال استان.

## وضعیت فعلی

زیرساخت Laravel 13، رابط Vue 3 و Inertia، صفحه ورود، داشبورد فارسی، دیتابیس اولیه و تنظیم PostgreSQL/Redis آماده است. زبان بصری محصول «مینیمال ورزشی» است و برای ارزیابی تجربه کاربری، پیش‌نمایش پنل مدیر، مربی، مسئول مالی و ورزشکار در دسترس قرار دارد.

رابط در موبایل و تبلت واکنش‌گراست: هر نقش نوار ناوبری پایین مخصوص خود را دارد، جدول‌ها در نمایشگر کوچک به کارت تبدیل می‌شوند و فرم‌ها، مودال‌ها، حضور و غیاب، مالی و پرونده ورزشکار برای عرض ۳۲۰ پیکسل به بالا بهینه شده‌اند.

خانه ورزشکار و والد با یک تجربه مستقل و ساده آماده شده است. عضو باشگاه بدون روبه‌رو شدن با ابزارهای مدیریتی، تمرین بعدی، وضعیت شهریه، رکوردهای عملکرد، روند حضور و پیام‌های باشگاه را می‌بیند. عکس ورزشکار از همین پنل قابل ثبت است و والد می‌تواند بین پرونده فرزندان متصل جابه‌جا شود.

مرحله کاربران و کنترل دسترسی نیز پیاده‌سازی شده است: نقش‌های مدیر، مسئول مالی، مربی، ورزشکار و والد؛ مدیریت حساب‌ها؛ فعال یا غیرفعال‌کردن کاربر؛ تخصیص مربی به تیم؛ هدایت نقش‌ها به پنل مربوط؛ و محدودکردن فهرست ورزشکاران مربی به تیم‌های تخصیص‌یافته.

مرحله مدیریت ورزشکار و تیم نیز آماده است: ثبت و ویرایش پرونده ورزشکار، فیلتر و جست‌وجو، عضویت تیمی، شماره پیراهن و پست تخصصی، تماس اضطراری و ملاحظات پزشکی، اتصال سرپرست، پروفایل کامل، ایجاد و ویرایش تیم، تعیین ظرفیت و تخصیص چند مربی. والد فقط پرونده فرزند متصل و مربی فقط ورزشکاران تیم‌های خودش را می‌بیند.

ماژول حضور و غیاب نیز عملیاتی است: ساخت جلسه تمرین، ایجاد خودکار لیست اعضای تیم، ثبت گروهی حاضر، غایب، تأخیر و غیبت موجه، زمان ورود، یادداشت مربی، نهایی‌کردن جلسه، گزارش افراد نیازمند پیگیری و نمایش نرخ و سابقه حضور در پرونده ورزشکار. داشبورد مدیر برای آمار ورزشکاران، تیم‌ها و حضور به داده‌های واقعی متصل شده است.

ماژول شهریه و امور مالی شامل صدور گروهی صورتحساب برای اعضای تیم، ثبت پرداخت نقدی، کارت‌به‌کارت و کارتخوان، پرداخت بخشی، محاسبه مانده و معوقات، لینک پرداخت مجزا، درگاه آزمایشی، رسید قابل چاپ و نمای اختصاصی ورزشکار و والد است. اتصال به درگاه بانکی واقعی نیازمند اطلاعات پذیرنده خواهد بود.

چرخه پرداخت آنلاین اکنون ساختار Production دارد: درخواست پرداخت قبل از انتقال ثبت می‌شود، Authority و مهلت اعتبار دارد، نتیجه Callback تأیید می‌شود و فراخوانی تکراری پرداخت مضاعف ایجاد نمی‌کند. درگاه به‌صورت Adapter طراحی شده و پس از انتخاب سرویس‌دهنده و دریافت مرچنت‌کد، پیاده‌ساز واقعی جایگزین Sandbox می‌شود.

ماژول ارزیابی عملکرد والیبال نیز شامل ثبت قد، وزن، دسترسی ایستاده، پرش عمودی، دسترسی اسپک، دسترسی دفاع و آزمون چابکی، یادداشت مربی، مقایسه با رکورد قبلی، نمودار روند و تاریخچه اختصاصی ورزشکار و والد است.

مرکز گزارش‌های مدیریتی نیز آماده است: فیلتر بازه زمانی و تیم، مقایسه تیم‌ها، شاخص‌های حضور، شهریه و عملکرد، هشدار جلسات تکمیل‌نشده، معوقات و ارزیابی‌های قدیمی، خروجی CSV سازگار با Excel و نسخه رسمی چاپ یا ذخیره PDF. مدیر همه گزارش‌ها، مربی فقط گزارش‌های تیم‌های خودش و مسئول مالی فقط گزارش‌های مالی را می‌بیند.

تنظیمات باشگاه شامل ویرایش مشخصات رسمی و اطلاعات تماس، مدیریت سالن‌های تمرین، ظرفیت و نوع کف سالن، مدیریت فصل‌های ورزشی و انتخاب فصل جاری است. سالن‌های فعال مستقیماً در فرم ساخت جلسه تمرین نمایش داده می‌شوند.

مرکز اعلان‌ها و یادآوری‌ها نیز شامل صندوق اعلان اختصاصی هر کاربر، وضعیت خوانده‌شدن، ارسال اطلاعیه عمومی، نقش‌محور و تیمی، تولید یادآوری شهریه معوق برای ورزشکار و والد و یادآوری جلسات تمرین آینده است. معماری کانال ارسال برای اتصال بعدی پیامک آماده شده است.

کانال پیامک به Outbox و Queue متصل است. پیام‌های شهریه، تمرین و اطلاعیه برای کاربران دارای شماره موبایل در صف مستقل قرار می‌گیرند، تا سه مرتبه تلاش می‌شوند و مدیر یا مسئول مالی می‌تواند وضعیت و خطا را ببیند و ارسال ناموفق را دوباره در صف بگذارد. Provider فعلی Sandbox است و Adapter سرویس واقعی پس از دریافت API Key جایگزین می‌شود.

دفتر تاریخچه فعالیت نیز برای مدیر باشگاه فعال است. ورود و خروج، تغییر پرونده‌ها، حضور و غیاب، پرداخت و عملیات مدیریتی با زمان، کاربر و IP ثبت می‌شوند و بدون نگهداری رمز عبور، اطلاعات کارت یا محتوای فرم قابل فیلتر و پیگیری هستند.

### پیش‌نمایش پنل‌ها

- مدیر باشگاه: `/dashboard`
- مربی: `/coach`
- مسئول مالی: `/finance`
- ورزشکار: `/athlete`
- کاربران و دسترسی‌ها: `/users` (فقط مدیر باشگاه)
- ورزشکاران: `/athletes`
- تیم‌ها و رده‌ها: `/teams` (فقط مدیر باشگاه)
- حضور و غیاب: `/attendance` (مدیر و مربی)
- مالی و شهریه: `/finance` (مدیر و مسئول مالی)
- شهریه ورزشکار: `/my-payments` (ورزشکار و والد)
- ارزیابی عملکرد: `/assessments` (مدیر و مربی)
- رکوردهای ورزشکار: `/my-performance` (ورزشکار و والد)
- گزارش‌های مدیریتی: `/reports` (مدیر، مربی و مسئول مالی با سطح دسترسی مخصوص نقش)
- تنظیمات باشگاه: `/settings` (فقط مدیر باشگاه)
- اعلان‌ها و یادآوری‌ها: `/notifications` (همه نقش‌ها با عملیات متناسب با دسترسی)
- تاریخچه فعالیت‌ها: `/activity-log` (فقط مدیر باشگاه)

## اجرای محلی سریع

پیش‌نیازها: PHP 8.3 یا بالاتر، Composer، Node.js 20 یا بالاتر.

```bash
composer install
npm install
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

برای پردازش پیامک‌های صف در یک ترمینال جداگانه:

```bash
php artisan queue:work --queue=notifications,default --tries=3
```

سامانه روی `http://127.0.0.1:8000` در دسترس خواهد بود.

### حساب نمایشی

- ایمیل: `admin@volleyball.ir`
- رمز عبور: `password`

حساب‌های نقش‌های دیگر نیز با رمز `password`:

- مربی: `coach@volleyball.ir`
- مسئول مالی: `finance@volleyball.ir`
- ورزشکار: `athlete@volleyball.ir`
- والد: `parent@volleyball.ir`

این حساب فقط برای محیط توسعه است و پیش از استقرار باید تغییر کند.

## اجرای PostgreSQL و Redis

```bash
docker compose up -d
copy .env.postgresql.example .env
php artisan key:generate
php artisan migrate --seed
```

PostgreSQL روی پورت `5433` و Redis روی پورت `6380` اجرا می‌شوند. برای Redis مقدار `REDIS_PORT=6380` را در فایل محیطی محلی قرار دهید.
